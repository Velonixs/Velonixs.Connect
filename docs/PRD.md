# Velonixs Connect PRD

## Product Summary

Velonixs Connect is a WhatsApp-powered customer engagement and order management platform for local businesses.

Version 1.0 focuses on restaurants while keeping the architecture open for grocery stores, fish markets, bakeries, pharmacies, sweet shops, and retail businesses.

## MVP Scope

- WhatsApp Cloud API webhook processing
- Customer profile and interaction history
- Catalog categories and products
- Order capture and order status tracking
- Staff notifications
- Admin dashboard for operations
- ASP.NET Identity user store
- JWT login endpoint
- Role-based Admin and Business Portal access
- Business-scoped owner, manager, cashier, and staff accounts
- Bootstrap-responsive browser interfaces

## Current Implementation Note

The current codebase preserves the restaurant MVP behavior while moving toward the broader Velonixs Connect platform structure.
